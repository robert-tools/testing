# @robert.tools/testing

A set of helper for testing

## Installation

```bash
npm install @robert.tools/testing
```

## Usage

```typescript
import { testing } from '@robert.tools/testing';

testing('hello'); // 'testing: hello'
```

## commands
After an npm install with `npm i` the following commands are available:
* initialize placeholders: `npm run init <semantic>`
* release a new version: `npm run release <semantic>`
